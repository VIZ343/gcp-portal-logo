# GCP Portal — Logo Loop

Proyecto de revisión independiente para animación vectorial del logo.

## Incluye
- Animación de entrada sencilla pero fluida.
- Texto estático después de la entrada.
- Loop interno del símbolo cada 30 segundos.
- Botones para revisar manualmente la entrada y el loop.

## Archivos
- `index.html`
- `style.css`
- `main.js`

## Uso
Abrir `index.html` directamente en navegador o ejecutar con Live Server.

## Notas de diseño
La animación busca reflejar los 12 principios de animación de forma sutil:
- anticipación;
- slow in / slow out;
- puesta en escena;
- follow-through ligero;
- secondary action;
- timing y spacing;
- appeal.

No se convirtió el texto a curvas para mantener edición rápida en esta fase de revisión.
